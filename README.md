# ChainVesper

ChainVesper enables real-time, distributed processing of cryptographic operations across a modular, auto-scaling system infrastructure.

ChainVesper is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainVesper.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure ChainVesper, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
